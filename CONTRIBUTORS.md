## How to Contribute

AiWA Identity Animation is an open-source WordPress Gutenberg block plugin
licensed under GPL-2.0-or-later. Community contributions are welcome.

To get started:

1. Fork the repository and create a feature branch.
2. Follow the [Contribution Guidelines](#contribution-guidelines) below.
3. Open a pull request against the `main` branch.

## Contribution Guidelines

1. **Code Quality** — follow WordPress Coding Standards (PHPCS) and
   `@wordpress/scripts` linting rules (ESLint + Stylelint).
2. **Testing** — test your changes on WordPress 6.3+ with PHP 7.4+.
3. **Accessibility** — ensure all user-facing changes meet WCAG 2.1 AA.
4. **Documentation** — update relevant docs for new features or changed behaviour.
5. **Security** — follow secure coding practices; report vulnerabilities privately
   (see [SECURITY.md](SECURITY.md)).

## Recognition
